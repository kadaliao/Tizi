# 常见问题

**连不上，或者连上了网页打不开**

先断开 Tunnelblick 等其他 VPN。桌面版点「遇到问题 → 网页打不开：重新挑选节点」：它先重新测速、换掉打不开的节点，还是不通再自动重新连接（这时要输入登录密码）；还不行就点「遇到问题 → 查看诊断详情」，看哪一项标了橙色或红色。终端版按 `7` 查看诊断，命令行运行 `tizi diagnose`。

**海外网站打不开**

多半是订阅下载失败或节点不可用。先看诊断页的「外网连通」：它经「外网代理」实际访问一次网站，写出流量走的是哪个节点。不通时到「策略」页点「测速」（终端版按 `t`），「自动选择」会按新结果重新挑节点；也可以给「外网代理」手动选一个延迟低的节点。订阅换了内容想立即更新时，删除 `~/.config/tizi/providers/subscription.yaml` 后运行 `tizi reload`。

**连上后访问不了内网**

服务端推送的路由和 DNS 不在 `.ovpn` 文件里。问管理员要内网的网段、域名和 DNS，填到「配置」页的内网设置里，见 [配置线路](configuration.md#内网)。

**微信图片发不出去**

桌面版点「遇到问题 → 微信图片发不出去」，或运行 `tizi recover-wechat`。

**怎么更新**

有新版本时桌面版会提示，点「更新」即可；也可以点菜单栏图标里的「检查更新…」，或运行 `tizi update`。

**关掉窗口后还连着吗**

连着。退出程序时会问你「停止并退出」还是「保持运行退出」。

**想让国内流量也走代理**

在高级模式的「配置」页把「国内流量」改成「走外网代理」，再点「重载 Mihomo」。

**已经装了 Tailscale 客户端**

和 Tizi 内置的 Tailscale 只开一个。同时运行时，连接期间 tailnet 地址会被 Tizi 的 TUN 接管而无法访问，诊断页会提示。

**Ubuntu 提示系统不支持**

需要 Ubuntu 22.04 / 24.04 x86_64 和系统自带的 `systemd-resolved`。运行 `tizi diagnose` 看缺什么；提示 `systemd-resolved 不可用` 时，运行 `sudo systemctl restart systemd-resolved` 后重试。
