# 手机导入与 TraceScope

## Clash Mi 扫码导入

电脑和手机连同一个局域网后，可以把当前配置导入手机上的 Clash Mi：

1. 桌面版高级模式点「Clash Mi 扫码导入」，终端版在「状态」页选同名操作，或运行 `tizi clash-qr`。
2. 在 Clash Mi 的「我的配置」点右上角 `+` →「扫描二维码」。
3. 导入完成后立即关闭分享。

导入的配置不包含内置 Tailscale 和分享链接写法的节点文件。二维码最多开放 5 分钟，使用随机路径；配置里有订阅地址、节点密码或证书，不要截图或转发二维码，也不要在不可信的局域网中使用。

## TraceScope 网络可视化看板

连接后运行 `tizi tracescope`，浏览器会打开 <http://127.0.0.1:8788/>，用 3D 地球显示当前公网连接的实时线路，按 `Ctrl+C` 停止。

首次运行需要本机已安装 Node.js 20+，会花 1–2 分钟准备运行环境。看板只监听本机回环地址，Mihomo 密钥不会进入页面或日志。端口、最多线路数和本机位置的设置见 [TraceScope README](../internal/tracescope/web/README.md)。
